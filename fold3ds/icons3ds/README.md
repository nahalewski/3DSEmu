Icons for the 3DS theme's HOME menu tiles.  Drop a square PNG named after
the tile here and it replaces the stand-in:

  games:      red.png blue.png yellow.png gold.png silver.png crystal.png
              firered.png leafgreen.png
  functions:  mods.png find.png online.png skins.png importers.png
              settings.png sync.png exit.png

A game with no icon shows its cartridge colour and letter.

Azahar (the 3DS emulator; fold3ds/azahar.lua): azahar.png (the folder),
folder_close.png, ctr_setup.png, and one az_<page>.png per icon in the
folder.  tools/make_azahar_icons.py draws them.
A 3DS game's tile shows the game's own icon.
