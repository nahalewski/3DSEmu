# DS and 3DS game card labels

`<code>.png`: the label art of a Pokémon DS or 3DS game card, named by the
product code in the game's header (the DS game code, or the last part of
the 3DS product code, which is the GameTDB id in Azahar's games.tsv field 9). The
providers can use it as a cart skin's `labelImage`.

- `ECLP.png`: Pokémon Alpha Sapphire (Europe), cropped from GameTDB's cart
  image (art.gametdb.com/3ds/cart).
