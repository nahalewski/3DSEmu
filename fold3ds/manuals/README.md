Scans of a game's printed manual, shown in front of the written pages of its
electronic manual (fold3ds/manual.lua): put the page images for a game in
`fold3ds/manuals/<version>/` here, or in `fold3ds_manuals/<version>/` in the
app's save folder, as `.png` / `.jpg`, named so they sort in page order
(`01.png`, `02.png`, ...).  `<version>` is `red`, `blue`, `yellow`, `gold`,
`silver`, `crystal`, `firered` or `leafgreen`.
